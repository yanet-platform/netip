# The Rust items the Lean transcriptions follow, each pinned by a hash of its
# tokens. Comments, doc comments and formatting are not tokens, so they do not
# change a pin. Any other change does, and `proofs/drift` then fails until the
# transcriptions are checked against the new code and the item is re-pinned:
#
#     cargo run --manifest-path proofs/drift/Cargo.toml              # check
#     cargo run --manifest-path proofs/drift/Cargo.toml -- bless     # re-pin
#
# A `[file]` line starts the items of a file of `src/`. An item line is
#
#     <item> <pin> <lean>...
#
# where `<item>` is `name`, `Type::name` or `Type::Trait::name`, without
# spaces, and each `<lean>` is a file under `proofs/`, optionally followed by
# `:<declaration>`, that transcribes the item or states a theorem about its code.
# `cargo run --manifest-path proofs/drift/Cargo.toml -- unpinned` lists the
# items no line names: formatting, `MacAddr`, the trivial conversions and
# accessors that no theorem is about.
